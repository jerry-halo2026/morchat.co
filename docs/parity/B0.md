# B0 能力件验收

> 这六个件是复刻 39 个外部工作台页面的公共依赖。缺一个，就有一批页面做不了。
> 每件都必须：API 签名稳定、五态齐全、测试覆盖、已知限制写清。

## 一览

| 件 | 组件 | 入口 | 消费者（页面） | 状态 |
|---|---|---|---|---|
| K1 通用看板 | `KanbanBoard<T>` | `@morechat/views/layout` | 招聘看板、线索商机、选题池、任务派发 | ✅ |
| K2 月历/周历 | `CalendarView` | `@morechat/views/layout` | 面试安排、跟进日历、拍摄排期 | ✅ |
| K3 雷达图 | `RadarChart` | `@morechat/views/blocks` | 能力画像、五维打分、竞品对比 | ✅ |
| K4 CSV 导出 | `toCsv` / `ExportButton` | `@morechat/views/blocks` | 几乎全部列表页 | ✅ |
| K5 文档编辑器 | `DocEditor` | `@morechat/views/editor` | 内容脚本、职位 JD、经营复盘 | ✅ |
| K6 列表分页 | `CollectionPager` + `footer` 插槽 | `@morechat/views/layout` | 全部列表 | ✅ |

## K1 通用看板

```ts
KanbanBoard<T>({ columns, items, columnOf, itemKey, renderCard,
                 onMove?, onMoveError?, onCardClick?,
                 loading?, empty?, emptyColumn?, label })
resolveDrop({ itemKey, overId, columnKeys, columnOfItem }) → KanbanDropTarget | null
```

- 落列判定抽成纯函数，列键优先于卡片键（拖到卡片上 = 落到该卡片所在列）
- 乐观换列用 `layoutSignature` 打标，props 一变就让位给真实数据
- `onMove` 返回 thenable 时卡片 `aria-busy`、不可再拖；reject 回滚并调 `onMoveError`
- **不重抛**：dnd-kit 丢弃 `onDragEnd` 的返回值，重抛只会变成全局 `unhandledrejection`

**已知限制**：不做键盘拖拽（Enter 用于打开卡片）；不做列内重排；卡片文本 `line-clamp-2`；`columnOf` 返回未声明的列键时该卡不渲染。

## K2 月历/周历

```ts
CalendarView({ view: "month"|"week", anchor, events, onAnchorChange,
               onSelectDay?, onSelectEvent?, loading?, label })
```

- 月：6×7 网格、周一起始、非本月淡化、每格最多 3 条 + `+N`
- 周：7 列 × 08:00–20:00 时段行 + 全天行
- **日期一律本地构造器重建**：不 `new Date("YYYY-MM-DD")`；`2026-02-31` 直接拒绝；`2026-01-31 +1月` 钳到 `02-28`
- 工具栏四词走 8 语言 `blocks.calendar.*`

**已知限制**：时段固定 08:00–20:00（21:30 的事件被 clamp 到 20:00 行）；无拖拽改期；无事件时长/重叠布局；月视图空事件只留空格不画标记。

## K3 雷达图

```ts
RadarChart({ axes, series, max?, label, height?, loading?, empty? })
```

- 颜色按序取 `--chart-1..5`，无硬编码色值，深色自动适配
- 轴标签按 code point 截 6 字，完整值进 `<title>`
- 全 0 或空序列渲染 `empty`（默认 `—`），不画空多边形

**已知限制**：>5 条序列颜色循环复用；值超 `max` 被 clamp 不报错；jsdom 无布局，回归测试依赖 recharts stub（仓库既有做法）。

## K4 CSV 导出

```ts
toCsv(rows, columns, { delimiter?, bom?, filename })   // 纯函数，node 可测
exportCsv(rows, columns, options)                       // 触发下载，必 revokeObjectURL
<ExportButton rows columns filename label />
```

- 与 `import.ts` 对称：含分隔符/引号/换行/首尾空白的单元格加引号，内部 `"` 双写
- `null` → 空串；数字不加千分位（否则回导会拆列）；`\r\n`；默认带 BOM
- 末条记录后不加空行；0 行也写表头

**已知限制**：不做 xlsx（需新依赖）；不做列选择弹窗；`ExportColumn` 无法从 `CollectionColumn` 机械派生，每个台账需逐列写 `value`（约 5–7 行/台账）。

## K5 文档编辑器

```ts
DocEditor({ value, onChange, mode?: "rich"|"plain", readOnly?, placeholder?,
            minHeight?, maxLength?, label, error?, toolbar? })
```

- `rich` 用 TipTap（starter-kit + link + placeholder + 自定义 `docTextLimit`），只开工具栏能触达的格式：粘贴带进来的 `codeBlock/code/underline/horizontalRule` 一律关掉
- `plain` 用 `<textarea>`，同一套 props
- `onChange`：`onUpdate` 只排一个 300ms 定时器，`blur` 立即 flush，卸载丢弃未发出的编辑 —— 连续打字不触发父组件重渲染
- `maxLength` 按纯文本计（rich 用 `getText()`，块间算 `\n\n`）；只拦"变长"事务，缩短永远放行
- 工具栏 11 项全部有对应扩展，图标只从 `@morechat/ui/icons`；link 用行内输入行而不是 `window.prompt`

**已知限制**：不做协同编辑、图片上传、AI 内联、markdown 往返；`mode` 固定在挂载时（切换会重挂载）；排版 CSS 以常量注入（仓库没有 typography 插件，现有 `prose.css` 会连带 code/mermaid/media 样式）。

## K6 列表分页

```ts
CollectionPager({ hasMore, loading?, loadedCount, total?, onLoadMore, label }): ReactElement | null
// CollectionList 新增可选插槽 footer?: ReactNode —— 渲染为列表最后一行
```

- **只做游标分页**：后端只有 `?cursor=&limit=`（默认 50 / 上限 200，无 offset）
- **原页没有页码条**：四个源 HTML 里 `每页/分页/页码/pageSize/currentPage` **全 0 命中**；台账是 `list.forEach` 进单个 `<tbody>`，`slice(0,10)` 只用于仪表盘 Top-N。所以"原页依赖页码"这个前提不成立
- `total` 只认 `/counts`；**list 响应的 `total` 是本页条数，传进来会画出"Showing 50 of 50"**
- 到底显示「没有更多了」；空列表整个 pager 不渲染

**已知限制**：不做页码跳转、不做每页条数选择器、不吃 offset。

## 对后续复刻的约束

1. **页面只允许 import 这六个入口**，不得自己再造看板/日历/雷达/导出/编辑器/分页。
2. 每件都有"已知限制"，页面复刻时若某页强依赖被砍掉的能力（例如拖拽改期），写进该页的**差异表**，不要临时改组件。
3. 组件不碰业务：数据获取、权限、写库全在页面层。
